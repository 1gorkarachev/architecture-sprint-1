# Описание

В качестве инструмента разделения монолита на микрофронты был выбран фреймворк Module Federation. Монолит был поделен с учетом определения доменных областей приложения: аутентификация, профиль пользователя и карточки мест.

Основные компоненты и микрофронты:
- Микрофронтенд аутентификации, отвечающий за аутентификацию пользователя в системе, регистрацию и авторизацию вл все приложении
- Микрофронтенд профиль пользователя, отвечающий за редактирование данных пользователя
- Микрофронтенд карточек с местами, отвечающий за CRUD с карточками мест


# Описание запуска приложения

Для запуска приложения необходимо перейти в поочередно в каталоги микрофронтендов и выполнить команды:

- для запуска микрофронта аутентификации
```
$ cd frontend/auth/
$ npm install
$ npm run start
```
- для запуска микрофронта профиля пользователя
```
$ cd frontend/user/
$ npm install
$ npm run start
```
- для запуска микрофронта карточек мест
```
$ cd frontend/place/
$ npm install
$ npm run start
```
- для запуска хоста
```
$ cd frontend/host/
$ npm install
$ npm run start
```
Далее перейти по адресу http://localhost:3000/
